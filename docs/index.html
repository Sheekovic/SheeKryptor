HOW IT WORKS

Simple outside.
Serious underneath.

SheeKryptor uses a versioned format shared with the desktop app and refuses modified data or incorrect passwords.

01

Authenticated encryption

AES-256-GCM protects confidentiality and detects tampering before a recovered file is downloaded.

02

Password hardening

PBKDF2-HMAC-SHA-256 performs 600,000 iterations with a fresh random salt for every file.

03

Zero uploads

The Web Crypto API does the work locally. The site has no server endpoint and its policy blocks network requests.

DESKTOP EDITION

For larger files and an offline workflow.

The Python desktop app processes files in chunks, supports the same .skrypt format, and can recover legacy SheeKryptor files.
